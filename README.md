# MASONOV TATTOO — пам'ятка

Мобільна сторінка для клієнтів: підготовка до сеансу і трекер загоєння.
Звичайні HTML + CSS + JS, без збирання. Працює офлайн і додається на головний екран.

## Як змінити текст

Увесь текст лежить у файлі **`content.js`**. Відкрийте його будь-яким текстовим редактором
(TextEdit у режимі «простий текст», VS Code тощо) і змінюйте лише те, що в лапках `'...'`.

- `**слово**` — жирний шрифт
- `==слово==` — синя плашка-маркер
- Пункти з позначкою `// ЧЕРНЕТКА` — тимчасовий текст для вкладки «Готуюсь до сеансу».
  Коли замінюєте текст, позначку можна видалити.
- Апостроф усередині тексту пишіть як `\'` (наприклад `пам\'ятка`) або ставте `’`.

Фонове фото: покладіть файл у папку `images` і в `content.js` впишіть
`backgroundImage: 'images/назва-файлу.jpg'`. Розмиття й затемнення додаються автоматично.

## Персональні посилання для клієнтів

| Що | Посилання |
|---|---|
| Класичне загоєння | `АДРЕСА/?tab=after&date=2026-11-20&mode=classic` |
| Плівка, 4 дні | `АДРЕСА/?tab=after&date=2026-11-20&mode=film&filmDays=4` |
| Підготовка до сеансу | `АДРЕСА/?tab=before&session=2026-11-20T14:00` |

Дата пишеться як `рік-місяць-день`, час — `години:хвилини`. Днів плівки: 3, 4 або 5.

## Telegram Mini App

Пам'ятка відкривається всередині Telegram за посиланням `t.me/ІМ'Я_БОТА/pamyatka`.

Персональні посилання для Telegram (в кінці додається `?startapp=...`):

| Що | Посилання |
|---|---|
| Класичне загоєння | `t.me/ІМ'Я_БОТА/pamyatka?startapp=after_20261120_classic` |
| Плівка, 4 дні | `t.me/ІМ'Я_БОТА/pamyatka?startapp=after_20261120_film4` |
| Підготовка до сеансу | `t.me/ІМ'Я_БОТА/pamyatka?startapp=before_202611201400` |

Дата пишеться без дефісів: `20261120` = 20 листопада 2026. Дата з часом: `202611201400` = 20 листопада о 14:00.

Кнопка календаря в Telegram відкриває пам'ятку у звичайному браузері, бо всередині Telegram файл календаря не відкривається.
Там кнопка підсвічується, і її треба натиснути ще раз.

Картинки для BotFather лежать у папці `telegram/`: `cover-640x360.png` для застосунку і `avatar-512.png` для аватара бота.

## Перевірка на комп'ютері

```bash
cd "/Users/uliarudenko/Сервіс догляд masonov tattoo"
python3 -m http.server 8080
```

Відкрийте http://localhost:8080. З телефона в тій самій Wi-Fi мережі відкрийте `http://IP-адреса-Mac:8080`.
IP-адресу Mac показує команда `ipconfig getifaddr en0`.
Без https офлайн-режим і «Додати на головний екран» повноцінно не працюють. Після публікації все запрацює.

Тести логіки трекера і календаря: `node tests/tracker.test.js`

## Публікація на Netlify (найпростіше)

1. Зайдіть на https://app.netlify.com/drop і зареєструйтеся (можна через Google або GitHub).
2. Перетягніть **усю папку** проєкту у вікно браузера.
3. За кілька секунд з'явиться адреса на кшталт `https://random-name-123.netlify.app`.
4. Site configuration → Change site name: впишіть, наприклад, `masonov-tattoo`.
   Адреса стане `https://masonov-tattoo.netlify.app`.
5. Щоб оновити текст, відкрийте сайт у Netlify → вкладка **Deploys** → перетягніть папку ще раз.
   Адреса не зміниться, тож QR-код на картках і далі працюватиме.

## Публікація на GitHub Pages (альтернатива)

1. Створіть акаунт на https://github.com і новий публічний репозиторій, наприклад `masonov`.
2. На сторінці репозиторію натисніть **Add file → Upload files** і перетягніть усі файли та папки проєкту.
   Папка `.claude` не потрібна. Натисніть **Commit changes**.
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
4. За 1–2 хвилини сайт з'явиться за адресою `https://ВАШ-ЛОГІН.github.io/masonov/`.
5. Щоб оновити текст, відкрийте `content.js` на GitHub, натисніть олівець (Edit), змініть текст і натисніть Commit.

## Файли

- `index.html` — каркас сторінки
- `content.js` — **увесь текст**
- `styles.css` — дизайн
- `app.js` — інтерфейс; `logic.js` — дати й трекер; `ics.js` — файли календаря; `storage.js` — збереження галочок
- `sw.js`, `manifest.json`, `icons/` — офлайн-режим та іконка застосунку
- `tests/` — автоматичні перевірки
